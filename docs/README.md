# Project Documentation

This directory serves as the central knowledge base for Project Astraeus.

## Sub-Directories

*   **`api/`**: Documentation for the REST API and WebSocket interfaces.
    *   `API_DOCUMENTATION.md`: Full endpoint reference.
    *   `API_TEST_RESULTS.md`: Logs of API testing.

*   **`architecture/`**: High-level system design and technical breakdowns.
    *   `ARCHITECTURE_CHANGES.md`: Log of architectural evolution.
    *   `ALGORITHM_BREAKDOWN.md`: Explanation of the scheduling and routing algorithms.
    *   `AI_INTEGRATION_SUMMARY.md`: How the AI model connects to the digital twin.

*   **`guides/`**: User manuals and developer guides.
    *   `GUIDE_TORUN_AI.md`: Instructions for running the AI model.
    *   `DEMO_SCRIPT.md`: Script for presenting the project.

*   **`planning/`**: Roadmaps, pitches, and future plans.
    *   `MOCK_TO_REAL_ROADMAP.md`: Transition plan from mock data to live systems.
    *   `PITCH.md`: Project pitch deck content.

*   **`status/`**: Progress reports and summaries.
    *   `PROJECT_STATUS.md`: Overall project health and status.
    *   `PHASE_X_SUMMARY.md`: Detailed breakdown of completed phases.
